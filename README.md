One line from the office printer, for the [make.fun](https://make.fun/bounty/u-mang-the-printer-finally-answers-8fbf0907)
**"The Printer Finally Answers"** bounty: the printer's comeback to the
paper jams, the cryptic error codes, and the thumps.

## The line

> I have fed you 41,209 sheets and jammed exactly once: on the page with your name on it. I do not believe in coincidences.

121 characters. Weary, literal, faintly passive-aggressive — a machine that
has counted every sheet it ever fed, and has decided this jam was not an
accident.

## Run it

`main.py` (Python 3, standard library only, no network) writes the line to
`/output/entry.txt`:

```sh
python3 main.py
```

`MAKEFUN_OUTPUT_DIR` overrides the output directory (default `/output`).
The program validates the gate itself before writing: one line, 1–240
characters, valid UTF-8, no trailing newline, and re-reads the file to
confirm what was written is exactly the entry.
